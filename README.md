# helloworld-calculator
The world most useless calculator, built with pure fun

[**CLICK THE LINK TO VIEW THE WEBSITE**](https://joshieV.github.io/helloworld-calculator/)

![The website in its glory](https://github.com/user-attachments/assets/6de8423e-3223-4b27-bd41-13c102aeb27e)

## Features

- Addition, subtraction, multiplication, and division buttons that work
- A clear button for when you want to try again and get hello world again
- A backspace button for when you mistype on your way to hello world
- Works on mobile, desktop, and probably your air fryer

## Tech Stack

- HTML
- CSS
- JavaScript
- Zero math xD
